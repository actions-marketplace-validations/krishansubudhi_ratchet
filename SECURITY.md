# Security Policy

## Supported versions

Only the latest release of `ratchet-size` on PyPI receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities through GitHub private vulnerability reporting:
https://github.com/krishansubudhi/ratchet/security/advisories/new

If that is unavailable, open an issue at https://github.com/krishansubudhi/ratchet/issues
without exploit details and ask for a private channel. Expect a first response within a week.

ratchet has no runtime dependencies and makes no network calls.
